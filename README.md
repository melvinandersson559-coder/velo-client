# VELO Client (Fabric 1.21.11)

En stilren blå klientmod för Minecraft Fabric 1.21.11 med FPS, koordinater, Toggle Sprint och en egen meny på **Höger Shift**.

## Så bygger du .jar-filen gratis utan Java (via GitHub)
1. Packa upp denna `.zip`-fil på din dator.
2. Gå till https://github.com och logga in (eller skapa ett gratis konto).
3. Klicka på **+** uppe till höger -> **New repository**. Döp det till `velo-client` och klicka på **Create repository**.
4. Klicka på **uploading an existing file**.
5. Dra in ALLA filer och mappar från den uppackade mappen (inklusive mappen `.github` – se till att dolda filer visas om du använder Mac/Windows, eller dra in allt på en gång) och klicka på **Commit changes**.
6. Klicka på fliken **Actions** högst upp på din GitHub-sida.
7. Klicka på bygget **Bygg VELO Client (.jar)** och vänta ca 1–2 minuter tills det blir grönt.
8. Längst ner under **Artifacts**, klicka på **VELO-Client-1.21.11-jar** för att ladda ner din färdiga `.jar`-fil!

## Så lägger du in den i Modrinth App
1. Öppna **Modrinth App** och skapa en instans med **Fabric 1.21.11**.
2. Installera **Fabric API** via **Add content**.
3. Klicka på de tre prickarna (...) -> **Open folder** -> öppna mappen `mods`.
4. Lägg in `velo-client-1.0.0.jar` i `mods`-mappen och starta spelet!
